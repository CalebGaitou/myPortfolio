# Caleb Gaïtou — Portfolio

Static HTML/CSS/JS site for GitHub Pages. There is no PHP and no database.

## Local preview

Open `Portfolio/index.html` in a browser, or from this folder run:

```bash
npx --yes serve .
```

Then visit the URL it prints.

## Publish on GitHub Pages

1. Create a GitHub repository and push this project.
2. In the repo: **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`.
5. Save. The site will be at `https://<your-username>.github.io/<repo-name>/`.
